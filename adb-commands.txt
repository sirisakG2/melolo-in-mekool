# Mecool / Melolo quick command reference

ADB executable:
~/Desktop/platform-tools/adb

Pair (first time, code from the TV's Wireless debugging screen):
~/Desktop/platform-tools/adb pair IP:PAIRING_PORT PAIRING_CODE

Connect:
~/Desktop/platform-tools/adb connect IP:DEBUG_PORT
or, after pairing, the fixed port:
~/Desktop/platform-tools/adb connect IP:5555

Devices:
~/Desktop/platform-tools/adb devices

Architecture:
~/Desktop/platform-tools/adb -s DEVICE shell getprop ro.product.cpu.abilist

Melolo package: com.worldance.drama

Install Melolo 4.9.2:
cd ~/Desktop/Melolo-4.9.2
~/Desktop/platform-tools/adb -s DEVICE install-multiple com.worldance.drama.apk config.armeabi_v7a.apk config.xxhdpi.apk

Check:
~/Desktop/platform-tools/adb -s DEVICE shell pm list packages | grep worldance

Launch (normal, portrait strip):
~/Desktop/platform-tools/adb -s DEVICE shell monkey -p com.worldance.drama 1

Freeform windows on (one time, then reboot):
~/Desktop/platform-tools/adb -s DEVICE shell settings put global enable_freeform_support 1
~/Desktop/platform-tools/adb -s DEVICE shell settings put global force_resizable_activities 1
~/Desktop/platform-tools/adb -s DEVICE reboot

Freeform windows off (then reboot):
~/Desktop/platform-tools/adb -s DEVICE shell settings delete global enable_freeform_support
~/Desktop/platform-tools/adb -s DEVICE shell settings delete global force_resizable_activities

Melolo TV tile package: com.mecool.melolotile

Install / update the tile:
cd mecool-tv && ./install.sh

Open Melolo full screen through the tile:
~/Desktop/platform-tools/adb -s DEVICE shell am start -n com.mecool.melolotile/.LaunchActivity

Open Melolo full screen from the Mac (backup):
cd mecool-tv && ./landscape.sh

Check window mode (freeform = full screen):
~/Desktop/platform-tools/adb -s DEVICE shell am stack list | grep -B1 worldance

Tile logs:
~/Desktop/platform-tools/adb -s DEVICE logcat -s MeloloTile

Remove the tile:
~/Desktop/platform-tools/adb -s DEVICE uninstall com.mecool.melolotile

Remove Melolo:
~/Desktop/platform-tools/adb -s DEVICE shell pm uninstall com.worldance.drama

LTvLauncher (optional, no longer needed): com.leanbitlab.ltvL
~/Desktop/platform-tools/adb -s DEVICE install ~/Desktop/LTvLauncher-armeabi-v7a-release.apk
~/Desktop/platform-tools/adb -s DEVICE shell pm uninstall com.leanbitlab.ltvL
